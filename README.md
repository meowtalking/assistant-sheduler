# Readme: Запуск проекта

## Пошаговая инструкция

Предварительно собрать все компоненты в одну дирректорию (assistant-sheduler), все файлы в ней:
- backend
- docker-compose.yml
- fronend
- mysql-data
- test-main.http
- venv

1. **Откройте проект в PyCharm**
   - Запустите PyCharm
   - Выберите `File` → `Open` и укажите папку с проектом

2. **Запустите Docker**
   - Убедитесь, что Docker Desktop запущен на вашем компьютере
   - В трее (области уведомлений) должен быть значок Docker (кит/кораблик)

3. **Откройте терминал в PyCharm**
   - В нижней части окна PyCharm найдите вкладку `Terminal`
   - Или через меню: `View` → `Tool Windows` → `Terminal`

4. **Перейдите в директорию проекта (если нужно)**
   ```bash
   cd путь_к_папке_проекта
   ```
   (Обычно PyCharm уже открывает терминал в нужной директории)

5. **Запустите сборку и запуск контейнеров**
   ```bash
   docker-compose up --build
   ```
   Эта команда:
   - Соберет образы (`--build`)
   - Запустит все сервисы, описанные в `docker-compose.yml`

6. **Откройте приложение в браузере**
   - После успешного запуска (когда в терминале перестанут появляться новые сообщения)
   - Откройте браузер и перейдите по адресу:
     ```
     http://localhost:3000
     ```

## Дополнительные команды

- Чтобы остановить контейнеры: `Ctrl+C` в терминале
- Чтобы остановить и удалить контейнеры: `docker-compose down`
- Чтобы просмотреть запущенные контейнеры: `docker ps`

Если возникнут проблемы - проверьте, что:
1. Docker запущен
2. Порты 3000 не заняты другими программами
3. В директории проекта есть файл `docker-compose.yml`
